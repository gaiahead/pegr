# PEGR v0.3 구현계획 — 최신 실제 순이익 기준 단순화

## Task 1. 계산 계약 변경

- 기존 중앙값·주주환원 테스트를 최신 실제 순이익 테스트로 교체
- 최신 손실을 과거 흑자로 대체하지 않는 회귀 테스트 추가
- 적정 시가총액을 10년 후 순이익 × 10년 후 PER의 할인값으로 한정

## Task 2. 데이터 생성기 단순화

- `Net Income Common Stockholders` 우선으로 최신 연간 행 선택
- 날짜 내림차순 첫 값을 기준 순이익으로 사용
- 현금흐름표 요청과 배당·자사주매입·주식발행 추출 제거
- `latest_net_income`, `latest_net_income_date`, `net_income_series` 저장
- 최신 순이익이 0 이하이면 가치평가 필드를 null 처리

## Task 3. 화면 단순화

- 주주환원율 열 제거
- 총순이익 최근 값에 결산연도 병기
- 최신 순이익이 0 이하인 종목의 시장 평가 입력 비활성화
- 설명 문구와 캐시 버전 갱신

## Task 4. 검증·배포

- Python·Node 테스트와 JSON 검증
- 25개 데이터의 최신일·유한값·초기 PEGR 확인
- Python·JavaScript 실데이터 계산 동등성 확인
- 로컬 브라우저에서 열 수, 값, 편집·초기화, 잘림과 콘솔 오류 확인
- 커밋·푸시 후 데이터 workflow와 최종 Pages 배포 확인
- 실페이지에서 동일 검증 반복
