# PEGR v0.4 구현계획 — PER형 성장 평가

## Task 1. 계산 계약 테스트

- 결산일에서 평가일까지 실제 경과연수를 검증
- `현재 총순이익 × (1 + g)^10 = +10년 총순이익` 회귀 테스트 추가
- 시장 내재 CAGR에서 `PEGR = 기준 10년 후 PER` 검증
- `가치배수 = PEGR ÷ 기준 10년 후 PER`과 괴리율 관계 검증

## Task 2. Python·JavaScript 계산 엔진

- 결산일을 실제 날짜로 파싱해 `경과일수 ÷ 365.2425` 계산
- 최신 총순이익에서 현재와 현재+10년을 순차 계산
- PEGR을 할인된 미래 순이익 대비 현재 시가총액의 PER형 배수로 변경
- 적정 시가총액·적정가·괴리율은 기준 10년 후 PER과 PEGR 비교로 유지
- 시장 내재 CAGR 역산 지수를 `경과연수 + 10년`으로 변경

## Task 3. 데이터·화면·문서

- 생성 데이터에 `current_net_income`, `earnings_10`, `valuation_multiple` 저장
- PEGR을 `15.00배` 형식으로 표시하고 기준 10년 후 PER 대비 색상 적용
- 총순이익 열을 `최근·현재·+10년`으로 확장
- README·설명·목표 문서와 캐시 버전을 v0.4로 갱신
