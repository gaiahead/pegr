# PEGR v0.3 목표 — 최신 실제 순이익 기준 단순화

## 배경

PEGR v0.2는 최근 양수 순이익 최대 3개의 중앙값과 과거 주주환원율을 함께 사용했다. 이 방식은 최신 실적의 증가·악화를 가리고, 적자 연도를 건너뛰며, 순수한 순이익 성장 평가와 현금흐름 평가를 혼합한다.

## 목표

- PBGR이 최신 실제 자본총계에서 시작하듯 PEGR은 최신 실제 연간 지배주주순이익에서 시작
- 최근 3년 중앙값과 양수 연도 선별 제거
- 배당·자사주매입·주식발행 및 주주환원율을 계산·데이터·화면에서 제거
- 최신 실제 순이익의 10년 성장과 10년 후 PER만으로 적정 시가총액 계산
- 최신 순이익이 0 이하이면 과거 흑자로 대체하지 않고 계산 불가 처리

## 계산식

```text
E_10 = 최신 실제 연간 지배주주순이익 × (1 + g)^10
적정 시가총액 = E_10 × 10년 후 PER ÷ (1 + 요구수익률)^10
PEGR = 현재 시가총액 ÷ 적정 시가총액
```

## 완료 조건

- Python·JavaScript 계산식에서 주주환원 입력과 현재가치 제거
- 생성 JSON에 최신 순이익·결산일·순이익 시계열만 보존
- 중앙값·주주환원 필드가 JSON과 화면에 남지 않음
- 한국 22개·미국 3개 총 25개 유지
- 초기 시장 내재 CAGR에서 전 종목 PEGR 1.000 확인
- 최신 손실 테스트에서 과거 흑자를 대신 사용하지 않음
- 로컬·Actions·Pages 검증 완료
