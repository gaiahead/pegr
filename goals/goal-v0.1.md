# PEGR v0.1 목표

# 개요

미국 상장기업을 대상으로 총순이익 성장과 지속 가능한 주주환원을 함께 반영하는 독립적인 PEGR 가치평가 모니터를 구축한다. PBGR의 사용 경험을 계승하되 `gaiahead/pegr` 공개 저장소와 별도 GitHub Pages 앱으로 운영한다.

# 핵심 가치평가

PEGR은 단순 PEG가 아니다. 현재 시가총액을 아래 적정 시가총액과 비교하는 10년 가치평가 배수다.

```text
E_t = 정규화 총순이익 × (1 + 시장 평가 이익 CAGR)^t
주주환원_t = E_t × 지속 가능 주주환원율
적정 시가총액 = Σ(주주환원_t ÷ (1 + 요구수익률)^t)
               + (E_10 × 종료 PER ÷ (1 + 요구수익률)^10)
PEGR = 현재 시가총액 ÷ 적정 시가총액
괴리율 = 적정 시가총액 ÷ 현재 시가총액 - 1
```

- `정규화 총순이익`: 최근 3개 연간 총순이익의 중앙값. 양수인 연도만 사용하며 2개 미만이면 계산 불가로 처리한다.
- `지속 가능 주주환원율`: 최근 최대 3개 연도의 `(현금배당 + 자사주매입 - 주식발행) ÷ 총순이익` 중앙값. 0~100%로 제한한다.
- 자사주매입과 배당은 현금흐름표 부호와 무관하게 현금유출 절댓값을 사용한다. 주식발행은 양의 유입액으로 차감한다.
- EPS가 아닌 총순이익과 총시가총액을 사용해 자사주매입에 따른 EPS 증가와 주주환원 반영의 이중계산을 피한다.
- 초기 `시장 평가 이익 CAGR`은 현재 시가총액이 내포한 값을 수치적으로 역산한다. 따라서 초기 PEGR은 1.000, 괴리율은 0.0%다.
- 사용자가 시장 평가를 수정하면 적정 시가총액·PEGR·괴리율·적정가·10년 후 순이익이 즉시 바뀐다.

# 대상과 데이터

- 초기 종목: Apple `AAPL`, Microsoft `MSFT`, Berkshire Hathaway Class B `BRK-B`
- 시장: 미국
- 통화: USD
- 데이터 수집: `yfinance`
- 종가: `regularMarketPreviousClose` 우선, `previousClose`, `lastPrice` 순서로 대체
- 주식수: `fast_info.shares` 우선, `sharesOutstanding` 대체
- 시가총액: 선택한 종가 × 주식수로 일관되게 계산
- 총순이익: `Net Income Common Stockholders` 우선, `Net Income`·`Normalized Income` 순서로 대체
- 배당·자사주매입·주식발행은 연간 현금흐름표의 가용한 표준 행 이름을 우선순위로 조회한다.
- 수집 실패 시 기존 `pegr_data.json`의 검증된 종목 데이터를 보존하고 실패 사유를 남긴다.

# 화면

- PBGR과 동일한 밝고 평평한 정적 HTML/CSS/JavaScript 대시보드
- 상단 공통 설정: 요구수익률, 종료 PER, 10년 할인계수, 저장 상태
- 기본값: 요구수익률 10%, 종료 PER 15배
- 표 순서:
  - 종목
  - 시가총액
  - 시장 평가 이익 CAGR 편집·초기화
  - 적정 시가총액
  - PEGR
  - 괴리율
  - 종가
  - 적정가
  - 순이익 기준
  - 순이익 +10년
  - 주주환원율
  - 주식수
- 요구수익률·종료 PER·종목별 시장 평가 오버라이드를 localStorage에 저장한다.
- 요구수익률 또는 종료 PER 변경 시 저장된 종목별 오버라이드는 유지하고, 미수정 종목의 내재 CAGR만 다시 역산한다.
- 종목별 초기화는 해당 종목 오버라이드만 제거한다.
- 모바일에서는 표를 축소하지 않고 가로 스크롤한다.
- 흰 배경, 핵심 표, 평면 박스, 불필요한 장식·그라데이션·과도한 설명을 배제한다.

# 수용 기준

- Python과 JavaScript에서 동일 입력의 적정 시가총액·PEGR이 허용오차 내 일치한다.
- 역산한 시장 평가 이익 CAGR을 다시 넣으면 PEGR 1.000과 괴리율 0.0%가 된다.
- 주주환원율이 0보다 크면 같은 성장률·종료 PER에서 주주환원 미반영 가치보다 적정가치가 커진다.
- AAPL·MSFT·BRK-B 세 행이 실데이터로 표시되며 `NaN`·`Infinity`가 없다.
- 입력 수정·저장·종목별 초기화가 실제 브라우저에서 동작한다.
- 표 셀 잘림·겹침·헤더/본문 불일치가 없다.
- 테스트·문법·JSON 검증이 모두 통과한다.
- GitHub Pages 배포가 성공하고 공개 URL에서 같은 동작을 재검증한다.
