# PEGR v0.4 목표 — PER형 성장 평가

## 배경

현재 PEGR은 `현재 시가총액 ÷ 적정 시가총액`으로 계산되어 적정 상태가 `1.000`이다. 이는 가격 괴리배수로는 유효하지만 PER 계열 지표처럼 `10배·15배`로 해석되지 않는다. 또한 최신 연간 순이익의 결산일부터 현재까지 경과기간이 10년 성장 계산에 반영되지 않는다.

## 목표

- PEGR을 현재 가격이 요구하는 성장 조정 `10년 후 PER`로 정의
- 최신 실제 연간 지배주주순이익을 결산일부터 현재까지 성장시켜 현재 기준 총순이익 계산
- 현재 기준 총순이익을 다시 정확히 10년 성장시켜 10년 후 총순이익 계산
- 기준 10년 후 PER과 PEGR을 직접 비교해 저평가·적정·고평가 해석
- 기존 가격/적정가 배수는 내부 `valuation_multiple`로만 유지하고 괴리율 계산에 사용

## 계산식

```text
경과연수 = 평가일 - 최신 결산일
현재 기준 총순이익 = 최신 실제 총순이익 × (1 + g)^경과연수
10년 후 총순이익 = 현재 기준 총순이익 × (1 + g)^10

PEGR = 현재 시가총액 × (1 + 요구수익률)^10 ÷ 10년 후 총순이익
적정 시가총액 = 10년 후 총순이익 × 기준 10년 후 PER ÷ (1 + 요구수익률)^10
가치배수 = 현재 시가총액 ÷ 적정 시가총액 = PEGR ÷ 기준 10년 후 PER
괴리율 = 적정 시가총액 ÷ 현재 시가총액 - 1
```

## 해석

- `PEGR < 기준 10년 후 PER`: 현재 가격이 더 낮은 종료 PER만 요구하므로 상대적 저평가
- `PEGR = 기준 10년 후 PER`: 적정 시가총액과 현재 시가총액이 같음
- `PEGR > 기준 10년 후 PER`: 현재 가격이 더 높은 종료 PER을 요구하므로 상대적 고평가

## 완료 조건

- 시장 내재 CAGR 초기값에서 PEGR이 `1.000`이 아니라 시장별 기준 10년 후 PER과 일치
- Python·JavaScript 계산 결과와 25개 실데이터가 일치
- 총순이익 `최근 → 현재 → +10년`이 같은 CAGR·경과기간으로 연결
- 사용자가 CAGR을 수정하면 PEGR·적정가·괴리율·현재/+10년 총순이익이 즉시 갱신
- 한국 22개·미국 3개 유지
- Actions·Pages·실서비스 검증 완료
