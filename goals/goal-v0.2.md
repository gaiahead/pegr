# PEGR v0.2 목표 — PBGR 한국 종목 통합

## 배경

PEGR v0.1은 미국 종목 3개만 지원한다. PBGR이 추적하는 한국 종목 22개를 같은 순서로 추가해 자본 성장과 순이익 성장을 동일 종목에서 비교할 수 있어야 한다.

## 목표

- PBGR `config.json`의 한국 종목 22개를 PEGR에 동일 순서로 추가
- 한국 종목은 네이버 금융의 종가·상장주식수와 Yahoo Finance의 연간 재무제표를 결합
- 한국·미국을 화면에서 분리하고 요구수익률과 10년 후 PER을 시장별로 관리
- 한국은 원화, 미국은 달러로 시가총액·종가·적정가·총순이익 표시
- 기존 미국 종목과 저장·초기화 동작 유지

## 계산 원칙

- 성장축은 EPS가 아닌 정규화 총순이익 CAGR
- 최근 양(+)의 연간 총순이익 3개 중앙값 사용
- 주주환원은 현금배당과 순자사주매입을 사용하고 주식발행을 차감
- 현재 종가를 정당화하는 시장 내재 순이익 CAGR을 역산
- 한국 종목의 우선주 코드가 있으면 보통주·우선주 상장주식수를 합산

## 완료 조건

- 한국 22개와 미국 3개, 총 25개 종목 생성
- 누락·중복·비유한 숫자 없음
- Python과 JavaScript 계산 결과 일치
- 초기 PEGR 1.000과 괴리율 0.0% 확인
- 한국 종목 편집·초기화가 미국 설정에 영향을 주지 않음
- GitHub Actions 데이터 갱신과 Pages 배포 성공
