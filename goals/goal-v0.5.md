# PEGR v0.5 목표 — 전통 PEG 의미 복원

## 배경

현재 화면은 PEGR을 성장 조정 10년 후 PER로 표시하고 `15배`를 기준으로 사용합니다. 사용자는 PEGR을 전통적인 PEG와 같은 의미로 사용하고, `1.0`을 정의상의 기준점으로 삼기로 결정했습니다. 다만 `1.0`을 자동적인 적정가·저평가 판정선으로 취급하지 않습니다.

## 목표

- PEGR을 `현재 PER ÷ 예상 EPS CAGR(퍼센트 숫자)`로 정의합니다.
- PEGR을 무단위 `0.500 / 1.000 / 2.000` 형식으로 표시합니다.
- 기준선은 `1.000`으로 통일합니다.
- `1 미만/초과`는 각각 성장 대비 PER이 낮음/높음을 뜻하며, 자동 저평가·고평가 문구를 사용하지 않습니다.
- 종목별 예상 EPS CAGR을 편집·초기화·저장할 수 있게 유지합니다.
- 저장값이 없으면 현재 PER과 같은 EPS CAGR을 기본값으로 사용해 PEGR을 `1.000`으로 초기화합니다.
- 전통 PEG만으로 객관적인 적정가를 산출하지 않으므로 적정 시가총액·적정가·괴리율·요구수익률·10년 후 PER·10년 순이익 예측을 제거합니다.
- 최신 실제 연간 지배주주순이익과 전체 시가총액으로 현재 PER을 계산합니다. 이는 주식수와 가격이 일관될 때 `주가 ÷ EPS`와 같습니다.

## 계산식

```text
현재 EPS = 최신 실제 연간 지배주주순이익 ÷ 현재 총주식수
현재 PER = 현재 주가 ÷ 현재 EPS
PEGR = 현재 PER ÷ 예상 EPS CAGR(% 숫자)
시장 내재 EPS CAGR = 현재 PER
```

대표 회귀 사례:

```text
PER 15 / EPS CAGR 15% = PEGR 1.000
PER 20 / EPS CAGR 10% = PEGR 2.000
PER 10 / EPS CAGR 20% = PEGR 0.500
```

## 완료 조건

- Python과 JavaScript가 대표 세 사례와 모든 실데이터에서 일치합니다.
- 초기 26개 종목은 PEGR `1.000`으로 표시됩니다.
- 예상 EPS CAGR 편집과 해당 종목만의 초기화·저장이 정상 동작합니다.
- 최신 순이익 또는 예상 성장률이 0 이하이면 PEGR을 계산하지 않습니다.
- 은퇴한 10년 후 PER·요구수익률·적정가·괴리율·10년 순이익 필드와 화면 문구가 남지 않습니다.
- 로컬 브라우저와 실서비스에서 한국 23개·미국 3개, 셀 잘림·겹침 없음, 콘솔 오류와 NaN 없음이 확인됩니다.
- GitHub Actions 데이터 갱신과 최종 Pages 배포가 성공합니다.
