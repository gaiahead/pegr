# PEGR 가치평가 모니터

한국·미국 상장기업의 현재 PER과 사용자가 입력한 예상 EPS 성장률을 비교하는 전통 PEG 방식의 정적 대시보드입니다.

- 공개 저장소: https://github.com/gaiahead/pegr
- 대시보드: https://dev.gaiahead.com/pegr/

## PEGR 정의

이 프로젝트는 PEGR을 전통적인 PEG와 같은 의미로 사용합니다.

```text
현재 EPS = 최신 실제 연간 지배주주순이익 ÷ 현재 총주식수
현재 PER = 현재 주가 ÷ 현재 EPS
PEGR = 현재 PER ÷ 예상 EPS CAGR(% 숫자)
```

대표 사례:

```text
PER 15 / 예상 EPS CAGR 15% = PEGR 1.000
PER 20 / 예상 EPS CAGR 10% = PEGR 2.000
PER 10 / 예상 EPS CAGR 20% = PEGR 0.500
```

- `PEGR < 1`: 예상 성장률에 비해 현재 PER이 낮습니다.
- `PEGR = 1`: PER 숫자와 예상 EPS 성장률의 퍼센트 숫자가 같습니다.
- `PEGR > 1`: 예상 성장률에 비해 현재 PER이 높습니다.

`1.000`은 수식의 기준점일 뿐 객관적인 적정가나 자동적인 저평가 판정선이 아닙니다. 성장의 지속성, ROIC, 부채, 현금흐름, 경기순환, 주식수 희석을 별도로 검토해야 합니다.

## 기준 순이익과 PER

- `Net Income Common Stockholders`를 우선해 공식 연간 재무제표의 최신 날짜 값을 사용합니다.
- 최근 3년 중앙값이나 과거 양수 실적으로 보정하지 않습니다.
- 최신 실제 연간 순이익이 `0 이하`이면 과거 흑자로 대체하지 않고 PER과 PEGR을 계산하지 않습니다.
- 한국 종목의 보통주·우선주 수량을 합산하면서 보통주 종가를 적용하는 경우 시가총액과 PER은 근사값입니다.

## 예상 EPS CAGR

`예상 EPS CAGR`은 사용자가 판단해 편집하는 성장률입니다. 저장된 값이 없는 초기 상태에서는 현재 PER과 같은 숫자를 넣어 PEGR을 `1.000`으로 표시합니다.

```text
초기 예상 EPS CAGR(%) = 현재 PER
초기 PEGR = 현재 PER ÷ 현재 PER = 1.000
```

초기값은 시장이 실제로 예측한 애널리스트 컨센서스가 아니라 **PEGR 1.000을 만드는 중립 역산값**입니다. 종목별 성장률을 수정하면 PEGR이 즉시 다시 계산됩니다.

전통 PEG만으로 객관적인 적정가를 정할 수 없으므로 이 화면은 적정 시가총액·적정가·괴리율을 표시하지 않습니다.

## 로컬 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 데이터 갱신

```bash
python3 gen_pegr_data.py
```

생성기는 가격·주식수와 연간 손익계산서만 사용합니다.

```bash
python3 -m unittest -v test_pegr.py
node --check app.js
node test_app.js
```

`.github/workflows/update.yml`이 매일 데이터를 재생성하고 테스트한 뒤 변경된 `pegr_data.json`을 커밋합니다.

## 한계

- 최신 한 해의 순이익은 일회성 이익·손실이나 경기 변동의 영향을 받을 수 있습니다.
- 사용자가 입력한 EPS CAGR의 기간과 근거에 따라 PEGR이 크게 달라집니다.
- 외부 증자·전환증권·자사주 소각으로 미래 주식수가 바뀌면 총순이익 성장과 EPS 성장이 달라질 수 있습니다.
- 본 화면은 투자 판단을 보조하는 참고자료이며 매수·매도 권유가 아닙니다.
