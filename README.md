# PEGR 가치평가 모니터

한국·미국 상장기업의 최신 실제 연간 지배주주순이익과 향후 총순이익 성장률을 이용해 적정 시가총액을 계산하는 정적 대시보드입니다.

- 공개 저장소: https://github.com/gaiahead/pegr
- 대시보드: https://dev.gaiahead.com/pegr/

## PEGR 정의

이 프로젝트의 PEGR은 일반적인 `PER ÷ EPS 성장률`이 아닙니다.

```text
10년 후 총순이익
= 최신 실제 연간 지배주주순이익 × (1 + 총순이익 CAGR)^10

적정 시가총액
= 10년 후 총순이익 × 10년 후 PER
  ÷ (1 + 요구수익률)^10

PEGR
= 현재 시가총액 ÷ 적정 시가총액
```

- `PEGR = 1`: 현재 시가총액과 모델 적정 시가총액이 같음
- `PEGR < 1`: 현재 시가총액이 모델 적정 시가총액보다 낮음
- `PEGR > 1`: 현재 시가총액이 모델 적정 시가총액보다 높음

## 기준 순이익

- `Net Income Common Stockholders`를 우선해 공식 연간 재무제표의 최신 날짜 값을 사용합니다.
- 최근 3년 중앙값이나 과거 양수 실적으로 보정하지 않습니다.
- 최신 실제 연간 순이익이 `0 이하`이면 과거 흑자로 대체하지 않고 가치평가를 계산하지 않습니다.
- 과거 연간 순이익 시계열은 출처 확인용으로만 보존합니다.

## 시장 평가

`시장 평가`는 현재 시가총액과 적정 시가총액이 같아지는 향후 10년 총순이익 CAGR입니다.

```text
시장 내재 CAGR
= [현재 시가총액 × (1 + 요구수익률)^10
   ÷ (최신 실제 연간 순이익 × 10년 후 PER)]^(1/10) - 1
```

대시보드에서 종목별 시장 평가를 수정하면 적정 시가총액, 적정가, PEGR, 괴리율과 10년 후 총순이익이 즉시 다시 계산됩니다.

## 지원 시장

- 한국: PBGR과 같은 순서의 22개 종목
- 미국: AAPL, MSFT, BRK-B
- 한국 가격·상장주식수: 네이버 금융
- 한국·미국 연간 순이익: Yahoo Finance 연간 재무제표
- 한국 통화: 원화
- 미국 통화: 달러

## 기본 가정

- 요구수익률: 시장별 `10%`
- 10년 후 PER: 시장별 `15배`
- 평가 기간: `10년`

## 로컬 실행

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다.

## 데이터 갱신

```bash
python3 gen_pegr_data.py
```

생성기는 현금흐름표를 요청하지 않으며, 가격·주식수와 연간 손익계산서만 사용합니다.

## 테스트

```bash
python3 -m unittest -v test_pegr.py
node --check app.js
node test_app.js
```

## 자동 갱신

`.github/workflows/update.yml`이 매일 데이터를 재생성하고 테스트한 뒤 변경된 `pegr_data.json`을 커밋합니다.

## 한계

- 최신 한 해의 실적이 일회성 이익·손실이나 경기 변동의 영향을 받을 수 있습니다.
- 10년 후 PER과 요구수익률은 사용자가 검토해야 하는 가정입니다.
- PEGR은 미래 현금흐름을 연도별로 추정하는 전통적인 DCF가 아니라, 미래 순이익에 종료 PER을 적용한 성장 평가모형입니다.
- 본 화면은 투자 판단을 보조하는 참고자료이며 매수·매도 권유가 아닙니다.
